Ниже — сборки под локальный запуск ComfyUI, Stable Diffusion WebUI (Automatic1111 / Forge), Ollama, LM Studio, vLLM и похожих инструментов. Выберите свой тип задач — получите три сборки (бюджетную, оптимальную и профессиональную), где каждая заточена именно под этот сценарий.

Показаны сборки: Универсальный вариант

Общие рекомендации

  • Охлаждение: для RTX 4070 Ti SUPER и выше — минимум 2–3 вентилятора (вдув + выдув). Флагманские CPU (7950X / 9950X / 14700K) лучше охлаждать двухбашенным суперкулером или СЖО 280+ мм.
  • Блок питания: запас 20–30 % от пикового потребления. Для AI‑нагрузок берите 80+ Gold — меньше нагрев и выше КПД при многочасовой работе.
  • Драйверы: используйте NVIDIA Studio (не Game Ready) — стабильнее работают с PyTorch, xFormers и CUDA 12.8+.
  • Место на диске: держите минимум 15–20 % свободного места на системном SSD — иначе NVMe теряет скорость, а подгрузка моделей замедляется.
